# Business Continuity & Disaster Recovery Project

This project was created as part of an Enterprise Network Administration course and focuses on Business Continuity Planning (BCP) and Disaster Recovery (DR) concepts within a fictional FinTech payment processing company.

The project includes:
- Business Impact Analysis (BIA)
- Recovery Time Objectives (RTO)
- Recovery Point Objectives (RPO)
- Critical system prioritization
- Threat analysis and risk assessment
- Disaster recovery strategies
- Downtime impact analysis

Key topics covered:
- Ransomware preparedness
- DDoS mitigation
- Cloud/server outage recovery
- Multi-region failover
- Backup and redundancy planning
